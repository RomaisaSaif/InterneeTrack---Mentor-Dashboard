Features:
- Intern Overview Panel – Provides mentors with a clear view of each intern’s profile, ongoing tasks, and performance metrics.
- Progress Tracking – Visual indicators for milestones and completion status.
- Task Management – Organized sections for assigning, reviewing, and updating tasks.
- Communication Hub – Integrated message and feedback area for smoother mentor-intern interaction.
- Clean Visual Hierarchy – A minimalist UI emphasizing readability and structured information flow.

Design Goals
- Enhance mentor productivity through intuitive dashboard flows.
- Maintain a balance between data density and visual simplicity.
- Develop a cohesive design system optimized for scalability.

Tools Used
- Figma – Layout design, prototyping, and component structuring.

Learnings
- This project deepened my understanding of dashboard UX, data visualization hierarchy,
  and the importance of consistent spacing systems. It also refined my approach to managing dense information while keeping interfaces user-friendly.
